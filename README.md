## 1. 프로젝트 개요
* **도메인:** 세무(국세, 지방세) 및 행정(인구) 데이터
* **목표:** 국세 및 지방세 세수 실적 데이터와 인구 통계 데이터를 통합·표준화하여, 연도·지역·세목별 세수 구조 변화 추이 및 1인당 실질 세부담액을 분석할 수 있는 Analytics Warehouse와 재현 가능한 dbt 기반 데이터 파이프라인 구축
* **작업 기간:** 2026년 9월 1일 - 2026년 9월 30일 (예정)

## 2. 비즈니스 문제 정의 및 논리적 흐름
**"재정분권 정책의 역설: 세원 편중 심화와 지방 소멸이 초래하는 지역별 1인당 세부담 가중 추이 분석 (2020-2024)"**

* **Q1. 정책 검증 (국가 단위):** 국가 차원의 재정분권 정책이 추진된 지난 5년간, 전체 조세 중 지방세의 징수 비율 추이 분석
* **Q2. 편중 현상의 역설 (지역 단위):** 소비와 자산이 밀집된 특정 지역에 세입 증가분이 초집중되어 지역간 수평적 불균형이 심화되었는지 확인
* **Q3. 1인당 세부담 가중치 (개인 단위):** 수도권 대비 비수도권의 1인당 실질 세부담액 증가 속도 비교

## 3. 원본 데이터 (Raw Data) 상세 및 전처리 기준
모든 원본 데이터는 **KOSIS 국가통계포털**을 출처로 합니다.

### 3.1. 활용 데이터 목록 및 구성
1. **`national_tax_raw.csv`**
   * **원천 출처:** KOSIS 국가통계포털_2.1.3 지역별·세목별 세수 현황[2005-]
   * **구성:** 연도별(2020-2024), 지역별(전국 17개 시,도), 세목별(전체 13개 세목: 소득세, 법인세, 상속세, 증여세, 종합부동산세, 부가가치세, 개별소비세, 주세, 인지세, 증권거래세, 교육세, 교통·에너지·환경세, 농어촌특별세)
2. **`local_tax_metro_raw.csv` & `local_tax_provincial_raw.csv`**
   * **원천 출처:** KOSIS 국가통계포털_1-1. 특별시 및 광역시 징수실적(총괄) / 1-2. 도별 징수실적(총괄)
   * **구성:** 연도별(2020-2024), 지역별(전국 17개 시,도), 세목별(전체 11개 세목: 취득세, 등록면허세, 레저세, 담배소비세, 지방소비세, 주민세, 지방소득세, 재산세, 자동차세, 지역자원시설세, 지방교육세)
3. **`population_raw.csv`**
   * **원천 출처:** KOSIS 국가통계포털_행정구역(읍면동)별/5세별 주민등록인구(2011년-)
   * **구성:** 연도별(2020-2024), 지역별(전국 17개 시,도), 성별(남/녀), 연령별(0-100+세, 5세 단위 분류)

### 3.2. 주요 전처리 및 품질 관리
* **데이터 범위 제한:** 2025년 데이터는 지방세 통계 미공표로 인해 데이터 정합성을 고려하여 분석 대상에서 제외
* **이상치/노이즈 제거:** 연도별 세수 추이의 비교 기준을 통일하기 위해, 분석 기간 내 폐지·개편되어 연속성이 떨어지는 세목 및 내국세가 아닌 관세는 제외
* **지표명 일원화:** 국세('세수현황')와 지방세('징수실적')는 원천 데이터 명칭이 상이하나, '실제 징수된 세금 수입'이라는 동일한 비즈니스 의미를 가지므로 최종 분석 지표명을 '세수실적(혹은 세수액)'으로 일원화
* **공간 차원 매핑:** 국세 원천 데이터의 집계 기준(충남·세종 통합)에 맞춰 정합성 확보를 위해 타 데이터(지방세, 인구)의 충남 및 세종 지표를 병합하여 일원화

## 6. 개발 및 커밋 컨벤션 (Development & Commit Convention)
본 프로젝트는 데이터 파이프라인의 정합성 유지와 더불어, 명확한 히스토리 관리 및 협업을 위해 아래의 명명 규칙과 Git 컨벤션을 엄격하게 준수합니다.

### 6.1. 핵심 기술 명칭 표준화
* **BigQuery**: 빅쿼리, bigquery 등 혼용 금지
* **dbt**: DBT, Dbt 혼용 금지
* **source**: dbt 파이프라인 내 원본 데이터 명세
* **dataset**: BigQuery 물리 데이터셋 인프라
* **raw data**: 원본 csv 파일 및 데이터 자체

### 6.2. Git Commit Prefix
* `feat`: 새로운 모델 생성 및 데이터 전처리 로직 추가
* `refactor`: 기존 스키마, 데이터셋 이름 변경 및 구조 개선
* `chore`: dbt 초기 세팅 등 기타 설정
* `docs`: README 및 명세서 작성
