# Analysis Notes

## Q1. 국세·지방세의 연도별 구조 변화

**모델:** `rpt_tax_revenue_by_year`

**Grain:** `tax_year`

**분석 기간:** 2020~2024년

### 1. 주요 관찰 결과

- 지방세 비중은 2020년 30.69%에서 2022년 27.66%까지 하락한 뒤, 2024년 30.02%까지 반등함.
- 지방세 비중이 가장 높았던 연도는 2020년(30.69%), 가장 낮았던 연도는 2022년(27.66%)임.
- 2024년 지방세 비중은 2020년 대비 0.67%p 낮음.
- 전체 세수 규모는 2022년 약 426.31조 원으로 분석 기간 중 최대치를 기록함.

### 2. 분석 범위 및 유의사항

- 본 분석은 16개 분석 지역에 귀속된 국세 13개·지방세 11개 법정 세목의 징수실적을 기준으로 함.
- 지역 미배분 수입분내국세·인지세와 국세·지방세 과년도수입은 분석 대상에서 제외함.
- 정부 공식 통계와 비교한 결과, 2020~2024년 누적 기준 국세 약 358.18조 원, 지방세 약 3.05조 원의 차이를 확인함.
- 국세는 지역 미배분 세수가 차이의 대부분을 차지했으며, 지방세는 과년도수입을 포함하면 공식 통계와 거의 일치함.
- 과년도수입은 개별 법정 세목으로 구분되지 않아 제외 기준을 유지하기로 결정함.
- 따라서 본 분석의 지방세 비중은 공식 전국 국세·지방세 비중과 직접 비교할 수 없음.

세부 검증 내용은 GitHub Issue #7 참고.
